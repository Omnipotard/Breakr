Install BREAKRInstaller BREAKR

Beta. Never unplug the FM-1 while it writes. The official firmware always goes back on with M-UPGRADE; holding OCT− at power-on starts the USB rescue. Bêta. Ne débranche jamais le FM-1 pendant l’écriture. Le firmware officiel se réinstalle toujours avec M-UPGRADE ; OCT− maintenu à l’allumage lance le secours USB.

  1. Switch the FM-1 on and plug it into this computer with a USB data cable.Allume le FM-1 et branche-le à cet ordinateur avec un câble USB de données.
  2. Close every other MIDI program (DAW, M-UPGRADE, another tab with this page).Ferme tous les autres programmes MIDI (DAW, M-UPGRADE, un autre onglet de cette page).
  3. Click Install, allow MIDI access, confirm. About a minute.Clique sur Installer, autorise l’accès MIDI, confirme. Environ une minute.
  4. Unplug nothing before “Done”. If the connection drops: plug in again and click Install, the write resumes.Ne débranche rien avant « Terminé ». En cas de coupure : rebranche et clique sur Installer, l’écriture reprend.
